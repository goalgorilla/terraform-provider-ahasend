# ahasend_smtp_credential (Resource)

Manages an AhaSend SMTP credential. There is no API update endpoint; changing `name`, `scope`, `sandbox`, or `domains` forces a new resource. The one-time `password` is returned on create and preserved in state.

## Example Usage

```terraform
terraform {
  required_providers {
    ahasend = {
      source = "goalgorilla/ahasend"
    }
  }
}

provider "ahasend" {
  api_key    = var.ahasend_api_key
  account_id = var.ahasend_account_id
}

variable "ahasend_api_key" {
  type      = string
  sensitive = true
}

variable "ahasend_account_id" {
  type = string
}

resource "ahasend_smtp_credential" "example" {
  name    = "app-smtp"
  scope   = "global"
  sandbox = false
}
```

## Schema

### Required

- `name` (String) Unique credential name within the account. Changing this forces a new resource.
- `scope` (String) Credential scope: `global` or `scoped` (requires `domains`). Changing this forces a new resource.

### Optional

- `domains` (List of String) Domain names for a `scoped` credential. Required when `scope` is `scoped`; must be omitted or empty when `scope` is `global`. Changing this forces a new resource.
- `sandbox` (Boolean) When true, the credential operates in sandbox mode. Changing this forces a new resource.

### Read-Only

- `created_at` (String) RFC3339 creation timestamp.
- `id` (String) SMTP credential UUID.
- `password` (String, Sensitive) One-time SMTP password returned only on create. Preserved in state; omitted from later reads.
- `updated_at` (String) RFC3339 last update timestamp.
- `username` (String) SMTP username.
