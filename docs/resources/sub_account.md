# ahasend_sub_account (Resource)

Manages an AhaSend Platform Partner sub account under the configured parent account. Requires parent API key scopes `sub-accounts:read|write|delete` and `sub-accounts:suspend` when using `suspended`.

## Example Usage

```terraform
terraform {
  required_providers {
    ahasend = {
      source = "goalgorilla/ahasend"
    }
  }
}

provider "ahasend" {
  api_key    = var.ahasend_api_key
  account_id = var.ahasend_account_id
}

variable "ahasend_api_key" {
  type      = string
  sensitive = true
}

variable "ahasend_account_id" {
  type = string
}

resource "ahasend_sub_account" "example" {
  name    = "Customer X"
  website = "customer.example.com"
}
```

## Schema

### Required

- `name` (String) Human-readable name for the sub account.
- `website` (String) Account website domain (FQDN).

### Optional

- `monthly_credit` (Number) Optional monthly sending cap. `0` means no cap.
- `suspended` (Boolean) When true, the sub account is suspended via the suspend endpoint. When false, unsuspend is called if previously suspended.
- `suspension_reason` (String) Reason sent to the suspend endpoint when `suspended` is true. Defaults to `Suspended via Terraform`.

### Read-Only

- `created_at` (String) RFC3339 creation timestamp.
- `domain_count` (Number) Number of domains owned by the sub account.
- `id` (String) Sub account UUID (child account ID).
- `last_activity_at` (String) RFC3339 timestamp of last recorded email activity, if any.
- `member_count` (Number) Number of direct members on the sub account.
- `parent_account_id` (String) Parent account UUID.
- `status` (String) Current sub account status (`active`, `suspended`, `parent-suspended`, or `deleted`).
