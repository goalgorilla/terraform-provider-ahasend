# ahasend_webhook (Resource)

Manages an AhaSend webhook for delivery and engagement events. Use `scope = "global"` for account-wide webhooks or `scope = "scoped"` with `domains`. The signing `secret` is returned on create and preserved in state (not updatable).

## Example Usage

```terraform
terraform {
  required_providers {
    ahasend = {
      source = "goalgorilla/ahasend"
    }
  }
}

provider "ahasend" {
  api_key    = var.ahasend_api_key
  account_id = var.ahasend_account_id
}

variable "ahasend_api_key" {
  type      = string
  sensitive = true
}

variable "ahasend_account_id" {
  type = string
}

resource "ahasend_webhook" "example" {
  name    = "delivery-events"
  url     = "https://example.com/ahasend/webhook"
  scope   = "global"
  enabled = true

  on_delivered = true
  on_bounced   = true
  on_failed    = true
}
```

## Schema

### Required

- `name` (String) Human-readable webhook name.
- `scope` (String) Webhook scope: `global` (account-wide) or `scoped` (requires `domains`).
- `url` (String) HTTPS endpoint that receives webhook events.

### Optional

- `domains` (List of String) Domain names for a `scoped` webhook. Required when `scope` is `scoped`; must be omitted or empty when `scope` is `global`. Omit on update to leave associations unchanged; set `domains = []` only when intentionally clearing them (global scope).
- `enabled` (Boolean) Whether the webhook is enabled. Defaults to true.
- `on_bounced` (Boolean) Trigger on bounce.
- `on_clicked` (Boolean) Trigger on click tracking.
- `on_delivered` (Boolean) Trigger on successful delivery.
- `on_dns_error` (Boolean) Trigger on DNS validation errors.
- `on_failed` (Boolean) Trigger on permanent delivery failure.
- `on_opened` (Boolean) Trigger on open tracking.
- `on_reception` (Boolean) Trigger on message reception.
- `on_suppressed` (Boolean) Trigger when a recipient is suppressed.
- `on_suppression_created` (Boolean) Trigger when a suppression is created.
- `on_transient_error` (Boolean) Trigger on transient delivery errors.

### Read-Only

- `created_at` (String) RFC3339 creation timestamp.
- `id` (String) Webhook UUID.
- `secret` (String, Sensitive) Webhook signing secret returned on create. Preserved in state; not returned reliably on later reads and not updatable.
- `updated_at` (String) RFC3339 last update timestamp.
